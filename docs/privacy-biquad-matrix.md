# v20m：八类型边界与完整 SDK 验收

本轮保持 57 项、P1–P14、A–L 的原范围，没有完成全量隐私覆盖。
引擎仍为 v20m（Mac `d18a79b5…`、Linux `d5e59bab…`），未修改内核或替换日常应用。

## 真实浏览器证据

八种 Biquad 类型 × 三档采样率 × 固定/定时变更 × 两次重复，共 96 图。
另有零频率、奈奎斯特频率、Q=0、零增益四类边界，共 192 图。
每种矩阵均运行 Mac scalar、Mac native 与同源 Linux scalar。
完整 288 个声道跨 CPU 相同；不只比较局部样本。
scalar 固定/动态矩阵的独立递归误差为零，边界矩阵最大误差约 3.73e-9。
参数生效前的完整前缀保持不变，生效后确有变化，重复和两条读出路径一致。

频率响应额外保存 magnitude/phase 的完整 Float32 字节，包括无效频率的 NaN。
两端 96 组响应相同。反例测试中只改变 NaN payload，数学检查和音频摘要仍通过，
跨平台检查则正确拒绝，避免把音频输出一致误当作全部读取接口一致。
新矩阵每模式拒绝 14 类坏记录，边界每模式拒绝 11 类，包括更新摘要后的错误分支。
最初未记录响应字节的抓取保留；最终以 `privacy-v20m-cross-biquad-response.json` 为准。

当前引擎平衡隐私模式的两套七 realm 检查通过：HTTP/JS 身份、内存提示、CPU 覆盖及
保留对象一致。该诊断不证明完整 Linux 字体、平台 API、任意 GPU 或正式 profile 激活。

## 完整产品候选

`out/mac-privacy-v20m-sdk-candidate/MetaBrowser.app` 包含完整固定版本 SDK 和重新编译的
Zig 插件。SDK-free 引擎原有 352 项全部保持一致，完整包为 373 项。
插件使用独立安装前缀构建，没有写入原先共享硬链接的 `zig-out` 插件。
实际 dyld 记录确认加载包内 SDK，未使用开发机外部 SDK 回退路径。

原生侧边栏、真实 SDK、原生浏览器工具经本地 provider 验收：点击和授权、工具图片、
文件与命令、MCP、Skill、截图附件、取消后续跑、独立会话、历史恢复及草稿均通过。
SDK 图片/宿主合约和本地 OAuth 合约（PKCE、state、刷新、撤销、恢复及协议中继）通过。
这些合成 issuer/provider 不代表真实 Metask 账户或真实模型业务已经验收。

首次完整 UI 测试失败被保留：旧 provider fixture 在 AX 未就绪时快速重复 observe，
消耗了有限重试。改为使用现有 `browser_wait` 做有界本地等待后通过；没有跳过动作、
更换执行器或捏造页面结果。

完整 SDK 候选已执行 100 次真实冷启动、原生正常退出、持久身份及 Canvas/音频/WebGL
稳定字段采集。独立验证逐份读取 100 份原始记录。模型端点被显式指向自有拒绝服务，
无启动任务、无模型 POST、无付费调用。此结果仅证明当前 native profile 的有限稳定字段；
不同模板/组合、真实业务长会话和七天观察仍未完成。

当前构建重新生成的 IDL 清单包含 18489 个潜在成员，完整性审计通过。
12 个成员关联了新 Biquad 运行证据，均标为部分覆盖，未把声明清单当作保护证明。
