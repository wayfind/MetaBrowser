# 原生侧栏设计

方向：精密工具感；浅石墨与冷灰背景，白色内容层，少量低饱和冷色强调。使用 Chromium Views、同一套原生矢量图标和 macOS 字体，不增加网页 UI 服务。

侧栏采用紧靠浏览器右边缘的 52px 功能栏，功能内容在左侧自适应展开。图标有工具提示与无障碍名称，选中项以白色圆角底区分；对话是默认页，模型配置不占据会话顶部。网页仍是主工作面。

| 图标页 | 真实数据与行为 |
|---|---|
| 对话 | 同一 Tab 的 MetaCodes Session 流式消息、发送、停止、新会话；工具进展摘要 |
| Skill | SDK 解析的本地 Skill 目录；不需要模型调用或 API Key；无远端 Skill 分发 |
| 连接器 | 标准 MCP 配置与 A2A 网关；外部任务进入当前 Tab 的会话 |
| 配置 | Metask 账号设备授权入口、模型/API Key、工作目录、文件查看、上下文压缩和检查点恢复 |

顶部使用原生可滚动 Tab 区分多个对话，最多八个。每个 Tab 有独立 Session、输入、记录和检查点文件；切换 Tab 不取消正在运行的会话。当前 SDK 工作线程仍串行执行多个 Session；这不是并行模型执行的承诺。关闭整个侧栏会取消其会话，当前没有跨重启恢复 Tab 布局或关闭单个 Tab 的操作。

授权区位于页容器之外，切换图标不隐藏待审批内容。拒绝和停止会完成待响应请求；外部 A2A 任务沿用同一授权界面。它没有“自动允许所有操作”的产品开关。

文件刷新不在 Chromium UI 线程做磁盘 I/O。控件访问名与工具提示用于键盘/辅助技术和测试驱动。事件仅显示工具摘要，不将图像 base64 或原始内部事件倾倒进对话。

范围：当前对话仍用原生文本滚动区，不是完整 Markdown/代码 diff 编辑器；当前工具摘要不是历史任务看板。动画、暗色主题与完整文件编辑器未在本次交付。真实截图与测试结果保存在 out/evidence；fixture 响应清晰标记为测试服务，不冒充真实模型推理效果。
